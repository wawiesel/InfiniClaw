17 const { systemsPath, systemRecord } = upsertSystemRecord(input, input.apply);
18 const beaconStatePath = writeBeaconState(input, input.apply);

30 beaconStatePath,

bootstrapSystem

Coordinates the beacon bootstrap flow:

  • validate input
  • update systems.json
  • write local beacon state
  • emit the relay start command

This is the core phase-1 beacon capability.
