# docs/

Project documentation. Not executable, not imported — reference only.

- `design/` — Architecture and design documents
- `faq/` — Frequently asked questions (operational how-tos)
- `solutions/` — Problem→cause→fix entries for recurring issues (operator knowledge base)
- `assets/` — Images, banners, static media
- `BUGS.md` — Known issues with priority and status (BUG-1 through BUG-30; BUG-24 through BUG-23 are the current open range)
- `NEXT.md` — Roadmap, Captain directives, planned work
