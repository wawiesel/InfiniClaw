# BUGS — Known Issues

When this file has content, the commanding engineer must address these items first, delegating and using threads as appropriate.

## Active Bugs

### 1. `secretsGitCommit()` silently swallows git stash errors

**File:** `src/relay.ts` ~line 1035

`secretsGitCommit()` catches git stash errors and silently sets `didStash = false` instead of throwing. Compare with `gitSync()` which correctly throws on unexpected stash errors. If stash fails for a real reason (permissions, disk space, corruption), the function continues and may leave the repo in a bad state.

**Fix:** Throw the error when it's not "No local changes", matching `gitSync()` behavior.

### 2. Dream prompt references removed "standing orders"

**File:** `src/relay.ts` ~line 1355

The dream period prompt says "optimize your standing orders for a fresh session" but standing orders have been removed from the codebase. The bot will waste time looking for something that doesn't exist.

**Fix:** Change to "prepare for a fresh session" or similar.

### 3. `STATUS_INDICATOR_RE` filters for patterns no longer generated

**File:** `src/message-filtering.ts` lines 28-31

The regex matches status indicator emoji patterns (💤, ⏳, 🔵, 🔷, 🔹) that are no longer generated by any bot. Harmless but dead code.

**Fix:** Remove the regex and the `STATUS_INDICATOR_RE.test(content)` call from `shouldIgnoreMessage()`.
